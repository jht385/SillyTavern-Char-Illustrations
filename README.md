# SillyTavern-Char-Illustrations-
一个能根据关键词在SillyTavern会话中插入本地插图的插件

当前功能:
- 为每个角色卡创建一个插图列表，本地上传JPG或PNG格式的图片，并设置触发关键词
- 关键词触发后会在聊天回复中插入插图
- 自动删除旧楼层的插图，只显示最新楼层的插图
- 可点击图片右上角，手动删除插图
- 可导出或导入插图配置
- 支持插图列表关键词搜索
- 可启用AI仲裁模式:  
  仲裁模式会分析当前楼层的情景，判断应该触发或屏蔽哪些关键词。如当前聊天，角色A脱掉了服装B换成了服装C，未启用AI仲裁模式的情况下，会同时触发服装B和服装C的关键词而会显示两张插图，启用AI仲裁模式之后AI会分析角色A已经换上了服装C，所以应该只保留服装C的插图。

注意事项:
- 该插件目前为先行版本，未经过大量测试，可能存在潜在问题
- 必须使用EDG、Chrome等带有V8引擎的浏览器
- 插图生成会占用浏览器JS堆内存，一次生成太多插图会超出浏览器JS堆内存的动态分配上限而导致网页崩溃
